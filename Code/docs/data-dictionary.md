# Data Dictionary

These are the shared definitions for the PoC's data. Code, documents and the dashboard use these names and meanings. Database tables (#19) and the finding structure (#46) must match them.

## Conventions

### Money

- Currency is **INR** throughout. Amounts are stored in **₹ crore** (1 crore = 10,000,000 rupees = 100 lakh) as decimal numbers, not floats.
- The `unit` column says what unit a field uses. Normalization rules for amounts reported in rupees, thousands, lakh or million are in [Normalization rules](#normalization-rules) (#15).
- Ratios and percentages are stored as plain decimals (`0.25` = 25%). They are shown as percentages in the UI.

### Periods

- Periods use **Indian financial years**, which run from April to March. FY2025 = 1 April 2024 to 31 March 2025.
- Quarters: Q1 = Apr–Jun, Q2 = Jul–Sep, Q3 = Oct–Dec, Q4 = Jan–Mar. So **Q1 FY2025 = April–June 2024**, and Q4 FY2025 = January–March 2025.
- Period labels are `Q1 FY2025` for a quarter and `FY2025` for a full year. `period_type` is `quarter` or `annual`.
- `period_end` is the last calendar date of the period (Q1 FY2025 → 2024-06-30).
- "Point in time" fields, such as balances, are as at `period_end`. "Flow" fields, such as revenue, cover the whole period.

### Standalone and consolidated

Standalone and consolidated figures are stored in the same table. The `statement_basis` field (`standalone` or `consolidated`) tells them apart. There are never separate undocumented tables for each basis.

### Missing values (null rules)

- A value that was not reported, could not be extracted, or failed validation is stored as **empty (NULL)**. It is never stored as `0`.
- `0` means the source document reports zero.
- Missing values are never estimated, carried forward or filled in (scope §6.4).
- Report placeholders such as "-", "—", "nil", "NA" and blank cells are read as empty (#15).
- An expected period with no filing appears as `missing` in the ingestion register (#13). It does not appear as zero values.

### Restatements

When a value is restated or revised, both the original and the revised value are kept, each with its own source filing (see `restated_from_metric_id` in [Financial metric](#financial-metric)). The revised value becomes current; the original is never overwritten or deleted.

### Information types

Every field shown in a finding has one of three information types (scope §8.3). They are always labelled in outputs:

- **Extracted fact:** a value taken directly from a public document.
- **Detected anomaly:** the result of a rule or model applied to extracted facts.
- **AI interpretation:** text generated by a model. It needs human validation before it is treated as a conclusion.

### Column meanings in the tables below

- **Type:** `text`, `integer`, `decimal`, `boolean`, `date`, `timestamp`, `enum(...)`, `list(...)`, or `id` (a reference to another entity).
- **Unit:** the unit for amounts, or `-` for none.
- **Period:** the period convention: `n/a`, `as at period_end`, `for period`, or `event date`.
- **Source reference:** where the value comes from.
- **Empty:** whether the field may be empty (`yes` or `no`).

## Company

One row per company in the approved sample (#6).

| Field | Meaning | Type | Unit | Period | Source reference | Empty |
| --- | --- | --- | --- | --- | --- | --- |
| `company_id` | Internal identifier | id | - | n/a | Generated | no |
| `name` | Current legal name | text | - | n/a | NSE/BSE company page | no |
| `former_names` | Earlier legal names within the five-year window | list(text) | - | n/a | NSE/BSE company page, annual report | yes |
| `nse_symbol` | NSE trading symbol | text | - | n/a | NSE company page | yes (if not listed on NSE) |
| `bse_code` | BSE scrip code | text | - | n/a | BSE company page | yes (if not listed on BSE) |
| `isin` | ISIN of the equity share | text | - | n/a | NSE/BSE company page | no |
| `sector` | Sector from the selection criteria (#5) | enum(banking, financial services, information technology, pharmaceuticals, manufacturing, retail, infrastructure, other) | - | n/a | Company sample (#6) | no |
| `sample_group` | Red-flag or control company | enum(red_flag, control) | - | n/a | Company sample (#6) | no |
| `listing_status` | Status at the evidence cut-off date | enum(listed, suspended, delisted, merged) | - | as at cut-off | NSE/BSE company page | no |
| `aliases` | Names used to match news: subsidiaries, promoters, key directors (#9) | list(text) | - | n/a | Annual report, company sample | yes |

At least one of `nse_symbol` and `bse_code` must be present.

One row per extracted financial value. Values are long-format: one row per company, period, basis and metric.

| Field | Meaning | Type | Unit | Period | Source reference | Empty |
| --- | --- | --- | --- | --- | --- | --- |
| `metric_id` | Internal identifier | id | - | n/a | Generated | no |
| `company_id` | Company | id | - | n/a | Company | no |
| `filing_id` | Filing the value was extracted from | id | - | n/a | Filing | no |
| `metric_name` | Standard metric name (list below) | enum | - | n/a | Mapping in #15 | no |
| `period_label` | Period the value refers to | text | - | for period | Document | no |
| `period_type` | Quarter or full year | enum(quarter, annual) | - | for period | Document | no |
| `statement_basis` | Standalone or consolidated | enum(standalone, consolidated) | - | n/a | Document | no |
| `value` | Normalized value | decimal | ₹ crore, or `ratio` for ratios | as at period_end (balances) or for period (flows) | Document, after #15 | yes (see null rules) |
| `unit` | Unit of `value` | enum(INR crore, ratio, count) | - | n/a | Normalization (#15) | no |
| `original_text` | Value exactly as printed, e.g. `(1,23,456.78)` | text | - | n/a | Document | yes (if no value printed) |
| `original_unit` | Unit stated in the report, e.g. `₹ in lakh` | text | - | n/a | Document | yes |
| `page_number` | Page the value was read from | integer | - | n/a | Document | yes |

| `is_current` | Whether this is the latest value for this company, period, basis and metric | boolean | - | n/a | Generated | no |
| `restated_from_metric_id` | Original value this row restates or revises | id | - | n/a | Restated filing (#43) | yes |

Standard `metric_name` values: `revenue_from_operations`, `total_income`, `total_expenses`, `operating_expenses`, `ebitda`, `profit_before_tax`, `net_profit`, `operating_cash_flow`, `total_debt`, `current_assets`, `current_liabilities`, `total_assets`, `fixed_assets`, `inventory`, `trade_receivables`, `loans_and_advances`, `contingent_liabilities`, `exceptional_items`, `foreign_currency_exposure`, `issued_share_capital`, `paid_up_share_capital`. #15 and #21 may add names; each addition must be listed here.
